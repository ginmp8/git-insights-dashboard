# Git Insights Dashboard 0.2.0

**Data registrada no changelog:** 2026-11-05. **Status:** versão descrita no projeto, com código publicado na branch main. Na verificação de 2026-11-05, **não foi localizada a tag v0.2.0**; esta nota não afirma a existência de um GitHub Release.

## Destaques

- Descoberta de repositórios públicos e privados acessíveis pela conta autenticada no GitHub CLI, com paginação e filtros por proprietário/visibilidade.
- Seleção de até 25 repositórios por lote, sem colar URLs ou confirmar cada clone individualmente.
- Clonagem sob comando com credenciais delegadas ao gh, sem gravar token em URL ou Git global.
- Nova aba **Mudanças ajustadas**: comparação de churn bruto, churn com detecção de renomeações (-M), churn ignorando espaços (-M -w), pares de caminhos movidos, possíveis mudanças lexicais de identificadores e arquivos de teste alterados.
- Exportação do diagnóstico e indicação da cobertura da amostragem.
- Manutenção das métricas legadas e do catálogo local.

## Compatibilidade e upgrade

Os dados do catálogo não exigem migração destrutiva conhecida nesta mudança. Preserve .git-insights-data/ ou configure GIT_INSIGHTS_HOME para apontar para os espelhos já existentes. Para descobrir repositórios da conta, instale e autentique o gh; o restante da análise local não exige GitHub CLI.

Consulte [Instalação](../docs/getting-started.md), [Projetos](../docs/features/projects-and-repositories.md), [Mudanças ajustadas](../docs/features/change-quality.md) e [Privacidade](../docs/privacy-and-security.md).

## Limitações conhecidas

- Churn e candidatos lexicais não provam valor, qualidade, impacto ou produtividade individual.
- O Git não detecta perfeitamente todos os movimentos; -w pode ocultar alterações funcionais em linguagens como Python.
- A análise aprofundada examina uma amostra configurável de até 500 commits filtrados por solicitação.
- A identidade de versão declarada em gitinsights/__init__.py ainda é **0.1.0**, divergindo do changelog e desta nota. Alinhar antes de declarar uma distribuição imutável v0.2.0.
- A tag v0.2.0 não foi localizada durante esta documentação; não presumir que o badge dinâmico exiba a versão.
