# Git Insights Dashboard 0.1.0

**Status:** registro retrospectivo do pacote inicial; não foi comprovada uma tag ou um GitHub Release correspondentes. **Data da versão:** não registrada no changelog.

## Principais funcionalidades

- Aplicação local em Python + Streamlit.
- Catálogo de projetos com múltiplos repositórios.
- Dashboard com histórico Git, commits, autores, churn e hotspots.
- Filtros de branches, pastas, datas e contribuidores.
- Comparação de branches e integração opcional de Pull Requests pelo GitHub CLI.
- Exportação JSON e CSV, sem exigir servidor de dados externo.

## Limites da versão

A versão inicial não oferecia listagem da conta GitHub para selecionar diversos repositórios nem diagnósticos separados de movimentações e renomeações de identificadores. O churn podia ser inflado por movimentações de arquivos.

## Evidência disponível

O [registro de validação do trabalho da 0.2.0](../VALIDATION.md) aponta uma baseline do pacote 0.1.0 com **18 testes aprovados** e SHA-256 do ZIP inicial. Essa evidência não comprova execução visual, publicação de release GitHub ou funcionamento em todos os sistemas operacionais.
